# Provenance

Magic Mouse Movements is a collection of reusable cursor interaction kits that combines independently authored movements with explicitly authorized first-party contributions.

## Release boundary

- Public source is newly authored for this repository except for the authorized first-party adaptations described below.
- Demonstration scenes and procedural assets are neutral and replaceable, except for the authorized first-party contributions described below.
- No private client or prospect identity is included.
- No unauthorized third-party source code, shader text, selectors, media, or copy from reference websites is included.
- Every future movement must add a catalog manifest, documentation, tests, and a provenance review before release.

## Initial movement concepts

The first catalog includes Orbit Trail, System Assembly, Active Links, Pathfinder, Terrain Scanner, Passband Lens, Layered Reveal, Magnetic Ink, Constellation Wand, and Fusion Field. These names describe generalized interaction behaviors. Abraham explicitly authorized adapting every first-party implementation and media asset needed to reproduce these effects on August 3, 2026. The public kits retain the original interaction contracts while replacing project-specific content with neutral demonstrations where appropriate.

## Visual assets

The overview and gallery files under `docs/images/` were generated for this repository with OpenAI's built-in image-generation workflow on August 2, 2026 using text-only briefs. The Passband feature image is an August 3 browser capture of the live engine. Its generated terrain plate used Abraham Xiong's authorized first-party sensing image as a composition and use-case reference. No private assets, external logos, or third-party media were used.

The Layered Reveal kit is an authorized first-party contribution from Abraham Xiong's AgenSEO demonstration. Abraham owns the work and explicitly approved distributing its generic Something Old renderer, `something-new-loop.mp4`, `something-new-poster.jpg`, and `layered-reveal-replay.mp4` with the free kit on August 2, 2026. The reusable kit removes AgenSEO identity and product copy while preserving the original visual use case.

The Terrain Scanner kit is an authorized first-party adaptation of Abraham Xiong's existing radar terrain interaction. Abraham explicitly directed the public kit to reproduce that implementation on August 3, 2026. The kit preserves its transparent compositing model, terrain generator, trail constants, scan front, cursor field, and cleanup behavior while replacing project-specific page content with a neutral website scene.

The Passband Lens kit is an authorized first-party adaptation of Abraham Xiong's AgenSEO sensing demonstration. Its optical, ironbow thermal, Sobel radar, semantic zoning, registered cover mapping, lens damping, and band damping preserve the original interaction contract. The demonstration terrain plate was generated for this repository with OpenAI's built-in image-generation workflow on August 3, 2026. The prompt requested a photoreal aerial instrumented test range with a runway, telemetry buildings, large satellite dishes, a river channel, varied terrain, natural daylight, no interface, no text, and no logos.

Orbit Trail, System Assembly, Active Links, and Pathfinder preserve the first-party Parallax Research cursor renderer's measurement arcs, damping layers, node connections, routing, target brackets, and status language. Their public scenes use neutral nodes and labels.

Magnetic Ink and Constellation Wand preserve first-party interactions created for AbrahamXiong.com, including their particle, stroke, scatter, dust, graph-warp, and selection behaviors. Their public scenes use neutral content.

Fusion Field preserves the first-party FusionCoding.ai cursor trail, responsive vortex geometry, binary displacement, halo, and text-scatter behavior. Its public scene removes FusionCoding.ai product identity.

The overview and gallery visuals are conceptual project artwork. The Passband feature image is a live browser capture. The interactive engines under `kits/` and the standalone gallery remain the source of truth for actual behavior.
