# Security Policy

## Reporting a vulnerability

Please do not disclose security issues in a public issue. Use [GitHub's private vulnerability reporting form](https://github.com/abexiong/Magic-Mouse-Movements/security/advisories/new) for this repository.

Include the affected movement, reproduction steps, browser details, and the impact you observed. Reports will be reviewed before a public fix or advisory is prepared.

Do not include credentials, personal data, or information unrelated to the report. If the private reporting form is unavailable, contact the repository owner through the public profile without publishing the vulnerability details.
