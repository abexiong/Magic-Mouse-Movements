# Third-party notices

The rendering core and movement engines have no runtime dependencies.

React is an optional peer dependency for the React adapter and remains subject to its own license. TypeScript and React type definitions are development dependencies only.

No third-party stock images, videos, fonts, shaders, or data files are distributed with the project. Repository concept artwork was generated specifically for Magic Mouse Movements with OpenAI's built-in image-generation workflow. The Layered Reveal loop, poster, replay, and Something Old renderer are first-party work created and contributed by Abraham Xiong. These assets are recorded in `PROVENANCE.md`.
